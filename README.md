# EstimAppart75 — version préparée pour migration

Cette archive contient une copie du site adaptée au nom commercial EstimAppart75 et au domaine estimappart75.fr.

## Contenu
- 31 pages HTML, dont les pages d'arrondissement et les articles.
- Feuilles de style et scripts JavaScript.
- Ressources graphiques et icônes.
- sitemap.xml, robots.txt et CNAME.

## Avant publication
1. Acheter et configurer le domaine estimappart75.fr.
2. Vérifier les informations des mentions légales et de confidentialité : les champs entre crochets sont des informations à compléter impérativement.
3. Vérifier les coordonnées et les conditions de transmission des demandes aux conseillers partenaires.
4. Vérifier le formulaire Formspree en effectuant un envoi de test.
5. Configurer GitHub Pages pour le nouveau domaine et activer HTTPS.
6. Mettre en place les redirections permanentes de l'ancien domaine vers les URL équivalentes du nouveau domaine chez un fournisseur compatible.
7. Mettre à jour le flux Web GA4 et ajouter la propriété du nouveau domaine dans Google Search Console.

## Important
Le fichier CNAME contient estimappart75.fr. Ne publiez pas cette version avant d'avoir acheté le domaine et d'être prêt à basculer GitHub Pages.

L'archive ne configure pas les DNS, les redirections de l'ancien domaine, Google Analytics ou Search Console. Ces opérations se font dans les services concernés.
